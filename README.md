# 🌳 Tamil Nadu Forest Analysis

> **Power BI Dashboard | Forest Cover, Biodiversity & Environmental Analytics**

## 📊 Project Overview

This project uses Power BI to analyze forest and environmental indicators across Tamil Nadu.

The analysis explores forest cover, forest density classes, district-wise forest distribution, forest types, biodiversity and other environmental indicators.

The dashboard is based on data reported in the **India State of Forest Report (ISFR) 2019 — Tamil Nadu** published by the Forest Survey of India.

---

## 🎯 Project Objectives

The project aims to:

* Analyze forest cover across Tamil Nadu
* Compare forest density categories
* Explore district-wise forest cover
* Analyze changes in forest cover
* Examine different forest types
* Explore biodiversity indicators
* Present environmental information through interactive visualizations

---

## 🌲 Key Indicators

The ISFR 2019 report records Tamil Nadu's forest cover at **26,364.02 sq km**, representing **20.27% of the state's geographical area**.

Forest cover is classified into:

* Very Dense Forest (VDF)
* Moderately Dense Forest (MDF)
* Open Forest (OF)

The report also records **714.72 sq km of scrub**.

---

## 📍 District-Level Analysis

The dashboard provides district-wise analysis of:

* Geographical Area
* Very Dense Forest
* Moderately Dense Forest
* Open Forest
* Total Forest Cover
* Percentage of Geographical Area
* Change compared with the 2017 assessment
* Scrub area

The source report provides district-level forest-cover figures for the 2019 assessment.

| Moderately Dense Forest |     11,029.55 |
| Open Forest             |     11,728.98 |
| **Total Forest Cover**  | **26,364.02** |

The report states that Tamil Nadu's forest cover increased by **83.02 sq km** compared with the 2017 assessment.

---

## 🌱 Forest Types & Biodiversity

The source report identifies **39 forest types** in Tamil Nadu under the Champion & Seth classification.

The analysis also covers biodiversity indicators, including observed species of:

* Trees
* Shrubs
* Herbs

The rapid biodiversity assessment reported **252 tree species, 313 shrub species and 87 herb species**.

---

## 🔥 Additional Environmental Indicators

The source material also includes information relating to:

* Forest fire-prone areas
* Wetlands
* Altitude-wise forest cover
* Slope-wise forest cover
* Forest cover inside and outside Recorded Forest Area
* Forest cover change matrix

These indicators provide additional dimensions for environmental analysis.
